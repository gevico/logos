# 大毛（DaMao）社区 IP 形象素材

本目录收录格维开源社区（GTOC）IP 形象“大毛”的首版正式素材，包括独立角色形象和角色设定表。

## 文件说明

| 素材 | PNG | WebP | SVG |
| --- | --- | --- | --- |
| 独立角色形象 | `damao-character.png` | `damao-character.webp` | `damao-character.svg` |
| 角色设定表 | `damao-character-sheet.png` | `damao-character-sheet.webp` | `damao-character-sheet.svg` |

其中，角色设定表的 PNG 与 WebP 为仓库和网页预览图；SVG 为可缩放的正式排版版本。

## 形象特征

- 白色长毛猫，左蓝右绿异瞳
- Q 版拟人化比例，造型简洁，保持成熟、稳重的气质
- 白色连帽衫搭配深色长裤和运动鞋
- 服装使用 GTOC 蓝色、青色与社区正式 LOGO
- 蓬松尾巴、粉色耳廓和鼻头，兼具亲和力与识别度

## 形象关键词

`稳重可靠`、`基础软件`、`冷静专注`、`工程伙伴`、`开源共建`、`探索未来`

## 格式用途

- **PNG**：透明背景角色图或设定表预览图，适合文档、海报和二次设计。
- **WebP**：体积较小，适合网站、公众号和社区线上内容。
- **SVG**：便于网页和设计工具统一导入、缩放与排版。角色 SVG 引用同目录 PNG；设定表 SVG 使用矢量文字和版式，同时引用角色 PNG 与仓库中的正式 LOGO。两者均不是对角色插画逐路径重绘的纯矢量稿。

## 推荐主色

- 科技青：`#7ED6FF`
- 深色：`#222831`
- 辅助绿：`#A8D08D`
- 白色：`#FFFFFF`
